# Fusion Ruleset v1.0

당일 방향성 판단을 **매크로 레이어**와 **차트 레이어**로 나눠 각각 독립 계산한 뒤,
융합 레이어가 두 값을 읽기만 해서 방향·확신도·플레이북을 만든다.

모드는 두 가지이고 **기본값은 `macro-only`** 다.

| 모드 | 입력 | 용도 |
|---|---|---|
| `macro-only` (기본) | 외부요인 + 리서치 관측 레벨 | 폰만 있을 때 받아보는 당일 방향성 |
| `fusion` | 외부요인 + v4 통합 번들 캔들 | 번들을 붙일 수 있을 때의 정밀 판단 |

`RULESET_VERSION = fusion-v1.0` · 구현: `src/engine/`, 테스트: `src/engine/__tests__/`

---

## 0. 설계 원칙

1. **레이어 잠금** — 매크로가 차트 값을 바꾸지 않고, 차트가 매크로 값을 바꾸지 않는다.
   융합은 두 레이어의 원값을 그대로 보존해 출력한다(`fusion.macro`, `fusion.technical`).
   v4 티켓 규범의 "기술분석을 먼저 잠근다"와 같은 규칙이다.
2. **결정적 계산** — 같은 입력이면 항상 같은 출력. 난수·시각 의존 분기 없음(now는 명시 인자).
3. **모르면 N/A** — 워밍업이 부족하거나 데이터가 없으면 추정하지 않고 점수를 빼고 플래그를 남긴다.
4. **방향은 분석 좌표** — 주문 실행·포지션 크기·레버리지 결정을 대신하지 않는다.

## 1. 매크로 레이어

### 1.1 입력

```jsonc
{ "key": "usRates", "stance": -2, "confidence": 0.9, "note": "10Y 4.745%(+7.5bp)", "source": "..." }
```

- `key`: 자산별 가중치 표에 정의된 키만 허용(오타는 `UNKNOWN_FACTOR` 플래그로 계산에서 제외).
- `stance`: **-2 ~ +2. 부호는 "이 자산 가격에 대한 압력"으로 이미 맞춰서 넣는다.**
  예) XAUUSD의 `dollar`에서 달러 강세는 `-2`, EURUSD의 `rateDiff`에서 미국 금리 우위 확대는 음수.
- `confidence`: 0~1. 데이터 신선도·출처 신뢰도. 생략 시 0.7.
- `note`: 숫자를 포함한 한 줄 근거(대시보드에 그대로 표시된다).

### 1.2 가중치 표 (자산별 합 = 1.0)

| NAS100 | | XAUUSD | | USOIL | | EURUSD | |
|---|---|---|---|---|---|---|---|
| usRates | 0.24 | realYield | 0.26 | supplyRisk | 0.24 | rateDiff | 0.26 |
| fedPolicy | 0.20 | dollar | 0.22 | inventory | 0.22 | fedPolicy | 0.18 |
| riskAppetite | 0.18 | fedPolicy | 0.18 | opec | 0.18 | ecbPolicy | 0.18 |
| megacapEarnings | 0.16 | safeHaven | 0.16 | demand | 0.16 | usData | 0.14 |
| breadth | 0.12 | inflation | 0.10 | geopolitics | 0.10 | ezData | 0.14 |
| dollar | 0.10 | flows | 0.08 | dollar | 0.10 | riskAppetite | 0.10 |

각 키의 부호 규칙은 `src/engine/weights.ts`의 `hint`에 적혀 있다.

### 1.3 계산

```
score      = Σ(w·c·stance) / Σ(w·c)          → -2 ~ +2
coverage   = Σ(w·c)                          → 0 ~ 1
dispersion = 가중표준편차(stance, w·c) / 2    → 0 ~ 1
confidence = coverage × (1 − 0.6 × dispersion)
```

- `coverage < 0.5` → `MACRO_COVERAGE_LOW`. 팩터를 덜 채우면 확신도가 자동으로 깎인다.
- `dispersion > 0.5` → `MACRO_HIGH_DISPERSION`. 팩터끼리 반대로 읽히는 상태.

## 2. 차트 레이어

### 2.1 입력

TF별 캔들 배열. 압축 행 `[ISO시각, 시가, 고가, 저가, 종가]` 또는 객체 형태 둘 다 받는다.
입력이 최신순이어도 과거→최신으로 정렬한다.

| TF | 융합 가중 | 최소 봉 수 | 내부 배분(추세/구조/모멘텀) |
|---|---|---|---|
| D1 | 0.30 | 60 | 0.6 / 0.4 / — |
| H4 | 0.30 | 60 | 0.5 / 0.5 / — |
| H1 | 0.22 | 60 | 0.5 / 0.2 / 0.3 |
| M15 | 0.18 | 40 | 0.2 / — / 0.8 |

봉이 모자라면 그 TF는 `TF_<tf>_WARMUP`으로 빠지고 남은 TF의 가중치로만 계산한다.

### 2.2 서브 점수 (각 -2 ~ +2)

**추세** — EMA20/EMA50과 ATR14로 정규화:
`2 × (0.4·스택 + 0.35·기울기 + 0.25·위치)`
스택 = tanh((EMA20−EMA50)/ATR), 기울기 = tanh((EMA20−EMA20[-5])/ATR), 위치 = tanh((종가−EMA50)/1.5ATR)

**구조** — 프랙탈(좌2/우2) 스윙의 마지막 두 고점·저점 비교:
HH+HL `+1.5` / LH+LL `−1.5` / HH+LL `+0.5` / LH+HL `0`, 종가가 마지막 스윙 고점 위면 `+0.5`(BOS), 저점 아래면 `−0.5`.
우측 2봉은 미확정으로 보고 스윙 후보에서 제외한다.

**모멘텀** — `2 × (0.5·tanh((RSI14−50)/12) + 0.5·tanh((종가−종가[-6])/1.2ATR))`

### 2.3 레이어 종합

```
score      = Σ(TF가중 × TF점수) / Σ(TF가중)
alignment  = |Σ(w·s)| / Σ(w·|s|)                 → 0 ~ 1 (TF 부호 일치도)
confidence = 0.2 + 0.55·alignment + 0.25·coverage
             × 0.85 (당일 레인지 > ADR20의 1.2배 → RANGE_EXHAUSTED)
             × 0.90 (ATR 백분위 < 0.3 → VOL_SQUEEZE)
```

- 변동성 국면: ATR14 백분위(최근 120봉) `<0.3 SQUEEZE`, `>0.7 EXPANSION`, 나머지 NORMAL.
- **무효화 레벨**: 롱 = 마지막 H1 스윙 저점 − 0.25·ATR, 숏 = 마지막 스윙 고점 + 0.25·ATR.
  H1이 없으면 H4, 그것도 없으면 전일 고·저로 대체한다.
- `macro-only` 모드에서는 차트 레이어를 아예 계산하지 않는다(점수 0, 플래그 없음).

### 2.4 v4 통합 번들 연결

`scripts/from-bundle.ts`가 rawbundle의 원시 캔들만 읽어 `candles` 블록을 만든다.
`hud_lite`/`by_tf`/`derived` 파생값은 읽지 않고, `is_complete=false` 봉은 버린다(ruleset v4.5.26 §1).
`time_utc`는 봉 시작 시각이며 이미 true UTC이므로 추가 시프트를 적용하지 않는다.

### 2.5 관측 레벨 (macro-only)

번들이 없을 때는 지지·저항을 **계산하지 않고** 리서치에서 읽은 숫자를 `levels`로 받는다.

```jsonc
"levels": { "last": 4042.97, "support": [4000], "resistance": [4100], "note": "...", "source": "..." }
```

이 값은 점수에 들어가지 않는다. 편향 확인·무효 문장과 재분석 트리거에만 쓴다.
(상승 편향이면 "저항 돌파 시 확인, 지지 이탈 시 무효")

## 3. 이벤트 레이어

| 티어 | 예 | 블랙아웃 | 확신도 상한 |
|---|---|---|---|
| 3 (1급) | FOMC, CPI, 고용보고서 | T−45분 ~ T+60분 | 45 |
| 2 (2급) | ISM, ADP, EIA 재고, ECB 회견 | T−20분 ~ T+30분 | 65 |
| 1 (3급) | 2차 지표 | T−10분 ~ T+15분 | 80 |

- 확신도 상한은 **유효구간(기본 6시간)** 안에 블랙아웃이 걸리는 이벤트만 반영한다.
- 표기는 48시간까지 끌어와서 `headline`으로 보여준다(상한 계산에는 넣지 않는다).
- 블랙아웃 진행 중이면 확신도를 30 이하로 눌러 신규 진입을 막는다.
- **이벤트는 방향을 바꾸지 않는다. 확신도와 진입 가능 시간대만 제한한다.**

## 4. 융합

### 4.1 레이어 가중

| 유효구간 최고 티어 | 차트 | 매크로 |
|---|---|---|
| 없음 / 3급 | 0.60 | 0.40 |
| 2급 | 0.55 | 0.45 |
| 1급 | 0.50 | 0.50 |

큰 이벤트가 걸릴수록 차트 비중을 줄이고 매크로 비중을 올린다.

```
eT = w_차트 × 차트컨피던스
eM = w_매크로 × 매크로컨피던스
score = (eT·차트점수 + eM·매크로점수) / (eT + eM)
```

### 4.2 합의 매트릭스

신호 인정 기준은 `|점수| ≥ 0.5`.

| 상태 | 조건 | 확신도 배수 | 플레이북 |
|---|---|---|---|
| 동조 ALIGNED | 양쪽 신호·같은 부호 | ×1.15 | 추세 추종, 되돌림 진입 |
| 부분 동조 PARTIAL | 한쪽만 신호 | ×0.90 | 절반 사이즈·짧은 목표 |
| 상충 CONFLICT | 양쪽 신호·반대 부호 | ×0.50 | 관망, 방향 베팅 금지 |
| 양측 중립 RANGE | 양쪽 모두 무신호 | ×0.60 | 레인지 양끝만 대응 |

### 4.3 확신도와 방향

```
확신도 = 100 × (|score|/2) × (0.5·차트컨피던스 + 0.5·매크로컨피던스) × 레짐배수
        → 이벤트 상한 적용 → 블랙아웃이면 30 이하로 절단 → 0~100 반올림
```

| 확신도 | 라벨 |
|---|---|
| 65 이상 | 높음 |
| 40 ~ 64 | 중간 |
| 40 미만 | 낮음 |

방향은 **확신도 35 미만이면 무조건 중립(0)** 으로 강등하고, 그 위에서만 점수로 이산화한다:
`≥1.0 → +2`, `≥0.35 → +1`, `≤−1.0 → −2`, `≤−0.35 → −1`, 나머지 0.

### 4.4 매크로 전용 모드 계산

차트 확인이 없으므로 융합식 대신 다음을 쓴다.

```
score      = 매크로 점수 그대로
확신도     = 100 × min(1, |score|/1.5) × (0.5 + 0.5×매크로컨피던스) × 0.9
             → 상한 70 → 이벤트 상한 → 블랙아웃이면 30 이하
방향 게이트 = 25 (융합의 35보다 낮되 확신도 라벨이 그만큼 낮게 붙는다)
```

레짐은 두 레이어 비교가 불가능하므로 **매크로 내부 일치도**로 판정한다.

| 상태 | 조건 | 표기 |
|---|---|---|
| ALIGNED | \|score\| ≥ 0.5, 분산 ≤ 0.5 | 요인 일치 |
| PARTIAL | \|score\| ≥ 0.5, 분산 > 0.5 | 우세·일부 상충 |
| CONFLICT | \|score\| < 0.5, 분산 > 0.5 | 요인 상충 |
| RANGE | \|score\| < 0.5, 분산 ≤ 0.5 | 요인 중립 |

플레이북은 진입 지시가 아니라 **주도 요인과 반대 요인을 이름으로 짚는 문장**이다.
예) `상승 편향 · 공급 차질 주도 · 반대 요인 OPEC+ · 85 상향 돌파 시 편향 확인`

블랙아웃 중에는 확신도와 무관하게 방향을 0으로 비운다.

### 4.5 유효시각과 재분석 트리거

`validUntil = min(현재 +6시간, 다음 세션 경계, 다음 블랙아웃 시작)`

재분석 트리거로 항상 남기는 것:
무효화 레벨 이탈 · 전일 고저 돌파 · 다음 블랙아웃 진입 시각 · 스냅샷 만료 시각 ·
변동성 확장 국면일 때의 급변.

## 5. 금지 사항

- 매크로 결론으로 차트 점수·TF 순위·차트 컨피던스를 고쳐 쓰기
- 커버리지가 낮은데 팩터를 지어내서 채우기(`MACRO_COVERAGE_LOW`를 감추기)
- 워밍업 부족 TF를 추정값으로 채우기
- 이벤트 티어로 방향 자체를 뒤집기(상한만 적용한다)
- macro-only 모드에서 무효화 "가격"을 계산해 제시하기(관측 레벨만 인용한다)
- 융합 확신도를 근거로 주문 크기·레버리지를 산출하기

## 6. 출력 계약

`public/macro.json` (version 2). v1 필드(`direction`, `confidence`, `rationale`, `drivers`,
`event`, `asof`, `setAt`, `source`)를 그대로 유지하므로 구형 화면도 계속 읽을 수 있고,
`fusion` 블록에 레이어별 원값·플래그·트리거가 모두 들어간다.
